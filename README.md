# OASIS INFOBYTE – Data Science Internship

## 📌 Internship Overview

This repository contains the projects completed as part of the OASIS INFOBYTE Data Science Internship. The projects focus on Data Analysis, Data Visualization, and Machine Learning using Python.

## 🚀 Projects

### Task 1 – Iris Flower Classification

**Objective:** To identify Iris flower species using Machine Learning classification models based on physical measurements.

- Dataset: Iris Dataset from Scikit-learn
- Technologies: Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn
- Activities:
  - Exploratory Data Analysis
  - Data Visualization
  - Classification Model Training
  - Flower Species Prediction
  - Model Evaluation

📂 Folder: `DataScience-Task1-IrisFlowerClassification`

📸 Screenshots: `iris_screenshots/`

---

### Task 2 – Unemployment Analysis

**Objective:** To analyze unemployment trends in India using data visualization and exploratory data analysis.

- Dataset: Unemployment in India.csv
- Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn
- Activities:
  - Data Cleaning and Preprocessing
  - Region-wise Unemployment Analysis
  - Monthly Trend Analysis
  - COVID-19 Impact Analysis
  - Correlation Analysis
  - Data Visualization

📂 Folder: `DataScience-Task2-UnemploymentAnalysis`

📸 Screenshots: `unemployment_screenshots/`

---

### Task 5 – Sales Prediction Using Python

**Objective:** To predict sales based on advertising expenditure using Machine Learning regression techniques.

- Dataset: Advertising.csv
- Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- Activities:
  - Exploratory Data Analysis
  - Advertising Feature Analysis
  - Correlation Analysis
  - Linear Regression
  - Polynomial Regression
  - Sales Prediction
  - Model Evaluation

📂 Folder: `DataScience-Task5-SalesPrediction`

📸 Screenshots: `sales_prediction_screenshots/`
