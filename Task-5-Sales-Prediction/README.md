# Sales Prediction Using Python

## Project Overview
This project predicts sales based on advertising expenditure using machine learning.

## Dataset
The dataset contains advertising expenditure on TV, radio, and newspaper, along with sales figures.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Models Implemented
- Linear Regression
- Polynomial Regression
- Random Forest Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Workflow
1. Data loading and cleaning
2. Exploratory Data Analysis
3. Data visualization and correlation analysis
4. Train-test split
5. Model training and prediction
6. Model evaluation and comparison

## Files
- Sales_Prediction.ipynb — project notebook
- Advertising.csv — dataset

## Conclusion
This project explores how advertising expenditure relates to sales and uses regression models to predict sales.
