Task 1 – Iris Flower Classification
OASIS INFOBYTE Data Science Internship
Objective
To train Machine Learning classification models to identify Iris flower species using physical measurements.

Dataset
The Iris dataset is loaded directly from sklearn.datasets.load_iris().

Technologies Used
Python
Pandas
Matplotlib
Seaborn
Scikit-learn
Jupyter Notebook
Project Workflow
Load the Iris dataset
Perform Exploratory Data Analysis
Visualize feature distributions
Discuss feature selection
Split data into training and testing sets
Train classification models
Evaluate model performance
Identify the best-performing model
Predict Iris flower species
Notebook
iris_classification.ipynb

Conclusion
The project compares classification models and identifies the best-performing model based on evaluation metrics.
